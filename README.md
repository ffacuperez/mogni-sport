# Mogni Sport

Sistema de gestión integral para gimnasio boutique.
Seminario de Práctica Profesional — UTN FRC, 2do cuatrimestre 2026.

## Stack tecnológico

- **Backend:** Java + Spring Boot
- **Frontend:** React (PWA)
- **Base de datos:** PostgreSQL

## Estructura del repositorio

- `backend/` — API REST (Spring Boot)
- `frontend/` — Aplicación web (React PWA)
- `docs/` — Documentación del proyecto

## Flujo de trabajo (GitFlow)

- `main` — código estable
- `develop` — integración del sprint actual
- `feature/hu-XX-descripcion` — una rama por historia de usuario

Todo cambio entra por Pull Request hacia `develop`.
